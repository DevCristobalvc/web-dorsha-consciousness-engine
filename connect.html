connect

Tres pasos y tu agente trabaja con memoria y criterio.

Pasos

Solicita tu token

Endpoint dce.devcristobalvc.com · entrega por canal privado, nunca en código.

Conecta tu agente

Claude Code — añade el server en .mcp.json:

// .mcp.json
{
  "mcpServers": {
    "dorsha-ce": {
      "type": "http",
      "url": "https://dce.devcristobalvc.com",
      "headers": { "Authorization": "Bearer TU_TOKEN" }
    }
  }
}

Pide memoria cuando la necesites

El agente decide cuándo recordar — nada de contexto inyectado a la fuerza.

Modo local

¿Prefieres correrlo tú? Sin token ni servidor:

$ pip install dorsha-consciousness-engine
$ ce mcp                    # stdio para Claude Code / Hermes
$ ce panel                   # panel de configuración local
