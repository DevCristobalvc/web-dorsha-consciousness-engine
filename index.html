La conciencia de tu agente,
como servicio MCP.

Dorsha Consciousness Engine da a cualquier agente (Claude Code, Hermes, Codex) tres superpoderes: memoria selectiva que se consulta como un tool, un juez dual que decide por si mismo, y un loop supervisado con presupuesto de iteraciones. DeepSeek by default.

Conectar en 3 pasos

Pide tu token de acceso

El endpoint gestionado vive en mcp.devcristobalvc.com. El token se entrega por canal privado (Telegram / email) — nunca va en codigo publico.

Registra el server en tu agente

Claude Code (`.mcp.json` en la raiz del proyecto):

// .mcp.json
{
  "mcpServers": {
    "dorsha-ce": {
      "type": "http",
      "url": "https://mcp.devcristobalvc.com",
      "headers": { "Authorization": "Bearer TU_TOKEN" }
    }
  }
}

Usa la memoria como un search

En medio del trabajo, el agente llama los tools cuando los necesita — no recibe contexto a la fuerza.

Tools que recibe tu agente

ToolQue hace
ce_memory_searchConsulta el RAG selectivo (prompts + respuestas propias + memoria curada) y devuelve resultados con citas exactas de sesion y timestamp.
ce_memory_saveGuarda una decision, leccion o dato que el agente decide conservar — pesa mas en el ranking.
ce_judgeClasifica un turno (ok / failed / uncertain / obvious_ask) y decide el camino: retry, advisor (DeepSeek, sesion nueva con contexto completo) o escalate.
ce_statusEstado del motor: chunks indexados, tarea activa, supervision, modelos.

Por que

Memoria selectiva

El RAG solo guarda lo que importa: prompts del usuario/conciencia, respuestas del agente y lo que el agente decide ce_memory_save. Los tool dumps jamas se indexan.

Juez dual

Un LLM juzga cada turno ambiguo en caliente; el humano juzga solo las limitaciones reales al cierre del ciclo. La conciencia nunca bloquea al worker.

DeepSeek by default

Advisor y judge usan la API oficial de DeepSeek — cero GPT, costos predecibles, sin dependencias de un solo proveedor.

Loop con presupuesto

Cuanto quieres que el agente siga solo: N iteraciones o un presupuesto de tokens por tarea. Al agotarse, devuelve el control al humano.

Provenance real

Cada chunk recuperado trae cita: (session:id msg:id @ timestamp). La memoria es auditable, no una caja negra.

Una base, tres canales

Mismo motor: stdio local (npx/uvx), HTTP gestionado (este subdominio) y panel de configuracion. El codigo es open source.
