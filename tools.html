tools

Los 4 tools MCP que recibe tu agente.

Disponibles

ce_memory_search

Consulta el RAG selectivo (prompts + respuestas propias + memoria curada). Devuelve resultados con citas exactas: sesion, mensaje y timestamp.

ce_memory_save

Guarda una decision, leccion o dato que el agente decide conservar. Pesa mas en el ranking de recuperacion.

ce_judge

Clasifica un turno: ok / failed / uncertain / obvious_ask. Decide el camino: retry, advisor (DeepSeek, sesion nueva con contexto completo) o escalate.

ce_status

Estado del motor: chunks indexados, tarea activa, supervision activa, modelos en uso.

Ejemplo

$ ce memory_search "decision sobre el deploy"
(session:abc msg:12 @ 2026-07-22) assistant: "usamos push a main para desplegar"
(__memory__) "Decision: el deploy usa push a main"

$ ce judge "el deploy fallo otra vez, no se que hacer"
action: advisor | reason: uncertain choice, consulting advisor
